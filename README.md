# BankOfTrinh

BankOfTrinh is a full-stack banking simulator built for C#, ASP.NET Core, Angular, SQL Server, Docker, and systems-design practice.

The project is intentionally being developed as a modular monolith. It is primarily a learning and portfolio project focused on building a realistic application incrementally without unnecessary overengineering.

## Projects

- `bankoftrinh.client` — Angular frontend
- `BankOfTrinh.server` — ASP.NET Core backend API

See [`BankOfTrinh.server/README.md`](./BankOfTrinh.server/README.md) for backend structure and development notes.
